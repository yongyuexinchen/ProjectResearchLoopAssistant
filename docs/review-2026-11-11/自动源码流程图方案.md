# 自动源码流程图与报告集成方案

日期：2026-11-11。评审基线：6b66b51c357fc893bb52c4d22d34777d09af4125。状态：待确认。

## 目标与效果

输入本地目录或 GitHub 仓库后，自动生成教程式的源码流程图；报告正文也出现同一份图。沿入口查看文件、函数、定义行、调用发生行，以及函数内部代码分段的用途。所有行号从本次实际读取的源文件计算。

## 方式选择

推荐：新增源码解析层，生成总览调用图和函数分步导航；继续使用现有 Mermaid 画布与按 run 保存的 ArchitectureDiagram。Python 使用标准库 AST；JavaScript/TypeScript/TSX 使用 Tree-sitter 语法树。两者均只解析文本，不执行输入仓库代码。这样能覆盖本项目及所给 Python 教程，保留现有目录、组件、类图。

未采用：继续按目录名/import 权重拼时序，无法证明具体调用行；交给 LLM 自由画调用链，无法保证文件和行号真实。若调用目标不确定，显示未解析，而不是猜一条边。

## 自动图与源码明细

1. 源码调用总图：文件 + 限定函数名 + 定义行；边标调用点行号。识别显式入口（HTTP 装饰器、main/入口文件等），区分入口候选与确定的注册语法。图表示静态调用引用，不声称一条请求一定经过全部节点。
2. 函数内部导航：按函数展示参数、返回语句、分支、循环、异常处理、调用位置和文档注释；每段有起止行、简短源码摘要和分类说明。
3. Python 解析本地直接函数、可明确解析的导入别名/模块调用、类内 self 方法；JS/TS 解析声明、箭头函数和相对导入直接调用。动态对象方法、反射、依赖注入、HTTP 跨进程跳转保留为未解析调用，不把同名函数强行连起来。
4. 用 文件路径 + 限定名 + 位置 的稳定标识，避免同名函数/类串线。源码内容与路径按敏感文件、生成目录、符号链接及根目录边界过滤。
5. 有文件数、单文件字节数、总解析字节数、函数/语句/边/画布节点预算；图显示截断原因。大总图只显示入口邻域，完整的已解析函数明细可搜索展开。没有支持语言时明确说明精细图不可用，不伪造调用链。
6. 每份代码记录内容摘要 hash；本次分析读到的源码和行号固化入图快照。修复单张图只从其自身快照渲染。

## 报告集成

- 普通报告和智能报告都追加“源码流程与架构图”章节，含图的来源、静态事实/启发式标识、Mermaid 源码和函数导航表。
- 报告取所选 run 的图；生成时复制图内容到报告快照，后续重画图、切换 run 或改代码不改变旧报告。
- 在线报告渲染 Mermaid 图，而不是只显示代码块。Markdown 导出携带 Mermaid 图与行号表。现有 PDF 导出也绘制保存的图（矢量简化版），保留节点、调用行号和图的限制说明；不访问网络渲染服务。
- LLM 只能增强讲解文字，不能改写确定性图和源码位置。

## 变更范围

新增 architecture 源码索引/解析模块与测试；集成 service、图快照校验、前端类型和源码明细查看；report service/renderer、报告页和 PDF。仅在所需位置修补快照隔离，不顺带重构 Worker 或修复整份评审清单。

## 验收

- 构造跨文件多层调用、同名函数、导入别名、类方法、分支/循环/异常和异步样例，逐条核对定义/调用行号。
- 不确定目标、坏语法、未知语言、超预算、路径穿越、符号链接都要有正确边界和明确提示。
- 图与 report run A/B 隔离；单图重生成、报告增强后不丢源码元数据；更改源码或新生成图不影响旧报告正文/导出。
- 在线报告真正显示图；MD/PDF 都包含本次报告保存的图与行号。验证 Python/TS 测试、类型检查和生产构建，并用当前项目生成实际示例。
- 评审清单单独交付，按严重程度列静态事实、已复现结果、风险推断；不把既有测试通过当作 MySQL/崩溃恢复已验证。
